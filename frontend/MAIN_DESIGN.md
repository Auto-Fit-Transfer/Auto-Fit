## 데이터 원칙과 미연결 항목

- Figma의 예시 이름·86점·FIT 2·320P를 실제 사용자 데이터처럼 고정하지 않는다.
- 티어 점수 구간/승급·강등은 미정이다. 5단계 안내만 제공하며 개인 티어를 임의 계산하지 않는다. 별도 Supabase 초안 테이블은 이번 프론트 커밋 범위에 포함하지 않는다.
- 마일리지·알림·커뮤니티 쓰기 API는 연결되지 않아 준비 상태다.
- 종합 분석 API에는 식단/운동별 상세 제안과 지표별 가감점이 없다. 서버 전략을 표시하고 식단/운동 화면으로 연결한다. 점수 기여도는 준비 상태로 표시하며 기존 분석 지표·기준·출처 상세를 유지한다.
- 식단 카드는 Main 최신안에 맞춰 사진과 냉장고 관리 UI를 표시하지 않는다. 추천 응답의 음식명과 1인 기준 분량을 식단명·레시피로 표시한다.
- 주간 운동은 `period=week`로 조회한다. 달성률은 횟수와 시간을 함께 반영하는 서버 계산값을 유지한다. 연속 운동 값은 서버가 제공하는 **최장 연속**임을 명시한다.
- 운동 시간의 `total_duration_seconds`는 분으로 변환하고 타임스탬프 날짜는 기기의 현지 날짜로 표시한다.
- 프로필/목표 조회 실패 중에는 저장을 막고 재시도를 제공한다. 목표 수정 시 기존 시작일을 보존한다.
- 회원 탈퇴는 모달에서 `탈퇴` 입력 후에만 요청한다. 테스트에서는 취소만 수행했고 실제 계정을 삭제하지 않았다.
