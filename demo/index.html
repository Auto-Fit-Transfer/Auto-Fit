실서비스 확인이 필요한 항목
API 테스트는 가짜 의존성을 사용하는 회귀 테스트입니다. 도메인 SQL 14종은 격리 DB에서, 보관·업그레이드 SQL은 로컬 Supabase에서 실행합니다. 로그인한 회원 흐름, OpenAI·CLOVA·지도 API 실호출, 실제 문서 판독, DNS·TLS를 통한 서비스 간 연결은 별도 확인이 필요합니다.
